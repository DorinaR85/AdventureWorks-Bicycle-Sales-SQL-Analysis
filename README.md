# AdventureWorks – Bicycle Sales & SQL Business Analysis

## Project Overview
This project focuses on analyzing business performance using the AdventureWorks database and SQL Server.

The analysis explores bicycle sales, revenue, profitability, seasonal trends, inventory management, and production performance to support data-driven business decisions.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
- Microsoft Excel
- Power BI

## Key Analysis Areas
- Sales and revenue performance
- Profitability and profit margins
- Seasonal sales trends
- Discounts and their impact on profitability
- Inventory and stock management
- Production losses and operational performance

## Project Objectives
- Analyze sales and revenue trends.
- Evaluate profitability and business performance.
- Identify seasonal patterns.
- Investigate inventory and production inefficiencies.
- Provide insights to support business decision-making.

## Project Files
- `Proiect.sql` – SQL queries used for data analysis.
- `Proiect SQL.docx` – Project documentation and business analysis.
- `Proiect SQL.pptx` – Presentation of the analysis and findings.

## Conclusion
This project demonstrates the use of SQL and business analysis techniques to transform raw data into meaningful insights and support strategic decision-making.
